# Rafha Moccamaster preview

Portable client demo of Rafha's anniversary coffee game and ten animated ad
concepts in 310x400 and 300x250. Website publishing is pending.

This is a demo, not an active prize competition. Signup is simulated; no email
addresses are saved or sent to Klaviyo. The review form stores notes only in
the visitor's own browser and offers a local download.

Only static preview assets are included. Private editing history, provider
credentials, server files and client reports are maintained separately.

The site is served from index.html at the repository root. The direct game uses
#leikur. Every standalone ad links back to the same hosted game.
